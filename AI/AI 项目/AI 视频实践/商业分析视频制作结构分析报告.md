# 商业分析视频制作结构分析报告

> 基于「小Lin说」两条视频（九号公司、AI资本混战）和「顾大夫」一条视频（双星名人家族内斗）的完整文案拆解

---

## 一、三个视频的制作结构拆解

### 视频1：从小众产品，到年入百亿（九号公司）— 小Lin说

**时长**：约17分钟 | **发布**：2022-07-29

| 阶段 | 时间段 | 内容 | 技巧 |
|------|--------|------|------|
| 钩子开场 | 0-40s | 个人经历：买平衡车→发现是上市公司→90亿营收营销费仅1.3% | 用"亲历者视角"引入，反常识数据制造惊讶 |
| 悬念设问 | 40-74s | "怎么闷声发大财的？" + 创始人背景交代 | 自问自答过渡，不拖沓 |
| 0→1阶段 | 74-165s | 8万→3万降价，旅游景点租赁切入 | 时间线推进，每一步都有"然后呢" |
| 1→10阶段 | 165-232s | 降到1万→胡海泉明星效应→营收2.3亿 | 意外因素（明星投资人）增加趣味 |
| 蛇吞象 | 232-325s | 被Segway起诉→反向收购→小米红杉入局 | 戏剧反转，"弱者逆袭"叙事 |
| **核心理论** | 325-577s | **自传播三要素**：传播度×正向比率×转化率 | 抽象出商业概念，用戴森电吹风做跨案例类比 |
| 突破点 | 577-735s | 轮毂电机技术突破→1999元→年入10亿 | 技术突破+价格突破双重高潮 |
| 10→100阶段 | 735-907s | 滑板车（共享经济）→电动两轮车（智能化） | 从单品到平台的战略升级 |
| 收尾升华 | 907-1008s | "产品得够硬" + CEO采访引用 | 回归价值观，引用金句收束 |

**结构特点**：以**成长时间线**为主轴，每个阶段都嵌入了"决策困境→选择→结果"的迷你故事。自传播理论是全片最核心的知识增量，占据约25%篇幅，是"看完能带走的东西"。

## 二、三个视频的共性结构（七阶段模型）

```
钩子开场 → 悬念设问 → 框架搭建 → 递进展开 → 概念提炼 → 类比佐证 → 价值收尾
 (吸引力层)                                    (认知层)              (收尾层)
```

| 阶段 | 功能 | 九号公司 | AI资本混战 | 双星名人 |
|------|------|----------|------------|----------|
| 钩子开场 | 30秒内抓住注意力 | 反常识数据 | 反常识投资 | 戏剧场景 |
| 悬念设问 | 制造好奇心缺口 | 怎么做到的? | 到底多乱? | 真假+谁对谁错? |
| 框架搭建 | 交代分析路线 | 成长时间线 | 四层产业链 | 事件-历史-多视角 |
| 递进展开 | 主体内容(50%+) | 降价→收购→扩张 | 逐对拆解投资关系 | 事件→历史→治理 |
| 概念提炼 | 知识增量 | 自传播三要素 | 牌桌论/捆绑风险 | 家族企业治理困境 |
| 类比佐证 | 加深理解 | 戴森电吹风 | 三国火烧赤壁 | 李锦记/双汇 |
| 价值收尾 | 可带走的收获 | 产品力是根本 | 留在牌桌上 | 避开家族企业 |

**关键发现**：三个视频虽然时长差异大（7-19分钟），但都严格遵循这七阶段结构。差异在于：
- **九号**最重"商业逻辑推演"，概念提炼占25%
- **AI**最重"信息密度梳理"，递进展开占60%
- **双星**最重"叙事戏剧性"，钩子和多视角翻转是核心

## 三、播放量高的原因分析

### 3.1 标题策略：好奇心缺口 + 关键词覆盖

| 视频 | 标题公式 | 心理触发 |
|------|----------|----------|
| 九号 | 小众产品 → 年入百亿 + 成功秘密竟然是… | 反差感 + 好奇心缺口（"竟然"） |
| AI | AI巨头 + 资本混战 + 到底是个什么情况？ | 热点关键词 + 简化承诺（"到底"暗示帮你理清） |
| 双星 | 84岁总裁 + 儿媳背刺 + 家族内斗解析 | 戏剧性事件 + 八卦驱动 + 专业承诺（"解析"） |

**共性**：全部使用了"？"或"…"制造悬念；全部包含至少一个"反常识"或"意外"元素；标题长度都在20-30字之间。

### 3.2 选题逻辑：熟悉×陌生

三个选题都遵循"**用大众熟悉的事物引入，揭示背后的陌生逻辑**"：

- 九号：平衡车大家都见过 → 但90亿营收/1.3%营销费没人知道
- AI：OpenAI/谷歌大家都听过 → 但之间盘根错节的投资关系没人理清
- 双星：家族内斗新闻大家都看到了 → 但背后的企业治理逻辑没人分析

### 3.3 叙事风格：像聊天不像上课

三个视频的口播都具备以下特征：

1. **口语化表达**："你敢信吗""好家伙""我跟你说""你先别急"
2. **自问自答节奏**：平均每30-60秒抛出一个小问题再解答，持续制造微悬念
3. **幽默穿插**：每隔2-3分钟一个轻松点（"有钱人家里怎么还有座机""这是企业还是朝廷""哭着把英伟达卖了"）
4. **长短句交替**：信息密集的长段后跟一个短句总结（"所以你看啊，虽然结果也是降价，但背后的逻辑不只是降价那么简单"）
5. **第二人称对话**："你是不是也想知道""你想啊""大家想想"

### 3.4 信息密度：高但可消化

- **具体数据密集**：金额、比例、时间点、市占率（九号视频中出现超过20个具体数字）
- **但通过比喻降低门槛**：自传播→"行走的广告"、AI资本→"牌桌"、家族内斗→"玄武门之变"
- **视觉辅助配合**：图表、关系图、时间线（从文案可推断视频有大量视觉元素）

### 3.5 情绪曲线设计

三个视频的情绪节奏都不是平铺直叙，而是有明确的"波峰波谷"：

```
惊讶 → 好奇 → 紧张(冲突) → 轻松(幽默) → 顿悟(概念) → 满足(结论)
```

### 3.6 知识增量：看完能带走东西

这是最关键的一点——三个视频都不是纯粹的"故事会"，每个都提炼出了可复用的商业概念：

- 九号 → **自传播三要素**（传播度×正向比率×转化率）
- AI → **牌桌论 + 捆绑式生存的系统性风险**
- 双星 → **家族企业"任人唯亲→能力不足→不愿放权"的死循环**

观众看完不只是听了个故事，而是获得了一个可以应用到其他场景的思维模型。

## 四、如何制作相似的商业分析视频

### 4.1 完整制作流程（六步法）

#### Step 1：选题（1-2天）

**选题标准清单**：
- [ ] 有"反常识"元素（成功不按常规套路 / 失败出人意料）
- [ ] 观众对主体有基本认知（熟悉的产品/公司/人物）
- [ ] 背后有不为人知的商业逻辑可挖
- [ ] 有足够公开数据支撑（财报/新闻/访谈）
- [ ] 能提炼出可复用的商业概念
- [ ] 话题有时效性或持续关注度

**选题来源**：
- 财报季的数据异常（如九号的低营销费）
- 行业大事件（如AI投资潮）
- 热点新闻的商业视角（如家族内斗→企业治理）
- 日常生活中遇到的产品的公司故事

#### Step 2：资料收集（2-3天）

**必备资料**：
- 公司财报数据（营收、利润、营销费用、研发投入）
- 行业报告（市场规模、竞争格局、趋势）
- 创始人访谈/演讲（提供叙事素材和金句）
- 新闻报道时间线（提供故事骨架）
- 竞品对比数据（提供差异化分析）

**信息处理**：
- 从所有数据中找出**最反常识的1个**→做钩子
- 梳理出**完整时间线**→做主体叙事骨架
- 找出**1-2个可提炼的商业概念**→做知识增量
- 找到**1-2个跨案例类比**→做认知桥梁

#### Step 3：脚本写作（2-3天）

**七阶段脚本模板**：

```
【钩子开场 30-60秒】
用一个反常识数据/戏剧场景/个人经历开场。
公式："你敢信吗？[反常识事实]"

【悬念设问 15-30秒】
抛出核心问题，承诺观众看完能获得答案。
公式："[核心问题]？今天就来聊聊。"

【框架搭建 30-60秒】
交代你将从什么角度分析，给观众一个"地图"。
公式："我们不聊XX，只看YY，一起捋一捋"

【递进展开 主体50-60%】
按时间线或逻辑链推进，每段包含"困境→选择→结果"。
关键：每2-3分钟一个小高潮（反转/意外/戏剧事件）

【概念提炼 10-15%】
从案例中抽象出可复用的商业概念。
关键：给概念起一个好记的名字（如"自传播""牌桌论"）

【类比佐证 5-10%】
用观众熟悉的事物做比喻，加深理解。
关键：类比要精准，不能为了类比而类比

【价值收尾 30-60秒】
升华观点，给出行动建议。
公式："[一句话总结] + [对观众的建议/启示]"
```

**口播写作要点**：
- 像跟朋友聊天一样写，不要像写文章
- 一句话一个信息点，不要长复合句
- 每30-60秒一个自问自答
- 每隔2-3分钟一个幽默点
- 用"你想啊""你猜怎么着""好家伙"等口语转折
- 关键数据要重复或强调

#### Step 4：视觉制作（2-3天）

**必备视觉元素**：
- 关键数据大字卡片（突出反常识数字）
- 时间线动画（展示发展历程）
- 关系图/架构图（理清复杂关系）
- 对比表格（竞品/案例对比）
- 人物/公司照片（增强代入感）

**风格建议**：
- 简洁为主，不要花哨
- 配色统一（参考小Lin说的蓝白风格）
- 动画服务于信息，不是装饰
- 关键数据用红色/大字突出

#### Step 5：录制剪辑（1-2天）

- 语速偏快但清晰（参考小Lin说约200-240字/分钟）
- 在关键转折处适当停顿
- 背景音乐轻快但不抢话
- 字幕必备（很多观众静音观看）

#### Step 6：标题封面（半天）

**标题公式**：
- `[反差元素A] + [反差元素B] + [好奇心缺口]`
- 例："从小众产品，到年入百亿，成功的秘密竟然是…"
- 例："84岁总裁遭儿媳背刺？双星名人家族内斗解析"

**封面建议**：
- 大字标题（3-5个字的核心词）
- 人物/产品图片
- 一个关键数字

### 4.2 复制成功路径的问题清单

#### 选题阶段问自己：

1. **这个案例有什么"反常识"的地方？**（如果你自己都不觉得意外，观众更不会）
2. **观众为什么会在意这个故事？**（跟他们的生活/工作/投资有什么关系）
3. **这个话题有没有"已知元素"可以做钩子？**（大家都见过的产品/都听过的公司/都看过的新闻）
4. **案例背后有没有可提炼的通用商业逻辑？**（还是只是个孤例故事）
5. **这个话题的时效性如何？**（能不能蹭到热点，还是已经过气了）
6. **有足够的公开数据支撑吗？**（没有数据支撑的分析就是空谈）
7. **这个案例的核心矛盾是什么？**（成功的：做对了什么别人没做的？失败的：做错了什么别人都懂的？）

#### 脚本阶段问自己：

1. **前30秒能不能让观众"哇"一下？**（如果不能，重新想钩子）
2. **我抛出的问题，观众会不会真的想知道答案？**（如果问题太学术或太冷门，换一个）
3. **我的分析框架观众能听懂吗？**（"四层产业链""成长三阶段"比"波特五力模型"更友好）
4. **有没有足够的具体数据支撑？**（每个关键论点至少1个数据）
5. **有没有跨案例的类比帮助理解？**（用观众已知的东西解释未知的东西）
6. **最后观众能带走什么 actionable 的收获？**（一个概念？一个建议？一个警示？）
7. **全程有没有至少3个"笑点"或"轻松点"？**（纯严肃分析会掉观众）
8. **有没有每隔2-3分钟一个小高潮？**（反转/意外/戏剧事件/关键数据）
9. **结尾是不是给出了明确的结论或观点？**（不要"见仁见智"式的和稀泥）
10. **口播读出来顺不顺？**（写完一定要大声读一遍，改掉所有拗口的地方）

#### 制作阶段问自己：

1. **视觉元素是否配合了口播的关键信息？**（说到数据时画面是不是有数据卡片）
2. **数据图表是否简洁易懂？**（一张图不超过5个信息点）
3. **节奏是否太快或太慢？**（7分钟视频约1800-2100字，17分钟约4000-4500字）
4. **标题是否同时有"好奇心缺口"和"关键词"？**（既要吸引人又要被搜索到）
5. **封面能不能在3秒内传达核心信息？**

#### 运营阶段问自己：

1. **发布时间是否踩着话题热度窗口？**（太早没热度，太晚没流量）
2. **简介/标签是否覆盖了搜索关键词？**
3. **有没有设置互动问题引导评论？**（评论量影响推荐算法）
4. **能不能做一个系列？**（单条视频的流量不如系列稳定）

### 4.3 快速启动建议

如果你是第一次做，建议按以下顺序练习：

**第一练（模仿结构）**：选一个你熟悉的商业案例，用七阶段结构写一篇3000字口播稿。不需要录制，只练结构。

**第二练（模仿风格）**：选一个小Lin说做过的案例，用她的风格重写一遍。对比原文找差距。

**第三练（独立选题）**：找一个她没做过的案例，从零开始选题→收集资料→写脚本→制作。

**推荐首批选题方向**：
- 你所在行业的"闷声发大财"公司（有数据反差）
- 最近热门新闻背后的商业逻辑（有时效性）
- 大家都用但没人分析过的产品（有熟悉感）
- 失败案例的商业教训（有警示价值）
