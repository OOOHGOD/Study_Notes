**SSH 密钥认证（SSH Key Authentication）**  
配合 **SSH Config 主机别名** 和 **ssh-agent 密钥代理**。

它的作用是让电脑安全连接网站服务器，并减少每次输入账号、服务器密码和密钥口令的麻烦。

简单理解：

- `ssh-keygen`：生成一对密钥
    - 私钥：保存在你电脑上，不能发给别人
    - 公钥：放到服务器上
- `ssh jfzy`：使用配置好的别名连接服务器
- `ssh-agent`：暂时记住密钥口令，避免每次重复输入
- `ssh config`：把 `jfzy` 指向 `root@8.138.105.190`

以后不需要再输入完整命令：

```
ssh root@8.138.105.190
```

只需：

```
ssh jfzy
```

对网站部署来说，它可以让工具安全地把网页文件上传到服务器、执行更新命令和检查网站状态。密钥认证通常比直接保存服务器密码更安全。
